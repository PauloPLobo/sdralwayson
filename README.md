
# SDR AIRA - Build APK sem Android Studio

1. Cria conta grátis em github.com
2. Cria novo repositório vazio
3. Faz upload de TODOS os ficheiros deste zip para o repositório
4. Vai ao separador "Actions" > vai aparecer "Build APK" a correr
5. Quando acabar (2 min), entra no workflow > em baixo em Artifacts > descarrega "SDR-AIRA-APK"
6. Dentro está o app-debug.apk pronto a instalar no telemóvel!

O APK já tem zoom, fullscreen, modo PC e fica sempre ligado com ecrã desligado.
